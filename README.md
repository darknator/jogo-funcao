# jogo-funcao
 Sobre o projeto
Function Archer é um jogo web onde o jogador controla um arqueiro e precisa acertar alvos desviando de obstáculos. A grande sacada é que a trajetória da flecha segue uma função matemática (parábola/quadrática), e o jogador precisa ajustar os coeficientes da função (a, b, c) para acertar o alvo.

Em vez de decorar fórmulas, o jogador vê a função acontecer na tela — aprendendo conceitos como:

Concavidade e coeficiente a

Deslocamento horizontal e coeficiente b

Ponto de partida e coeficiente c

Raízes, vértice e ponto máximo

Aprender funções nunca foi tão divertido (ou tão desafiador 🎯).
